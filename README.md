# GreenMind-FX

Built for UTMxHACKATHON 2026
A minimal, component-driven dashboard built with React, Vite and Tailwind where it is fast to run and easy to extend.

## Quick Start

Prerequisites
- Node.js 16+ (or compatible)
- npm or yarn

Install and run locally

```bash
npm install
npm run dev
```

Build for production

```bash
npm run build
npm run preview
```

## What this project contains

- Lightweight Vite + React + TypeScript setup
- Tailwind CSS for styling and utility-first theming
- App structure with feature pages and reusable UI components

Main folders

- `src/` — application source
- `src/app/` — app entry, routes and pages
- `src/app/components/` — reusable UI components and layout
- `src/styles/` — global styles and Tailwind config

## Development notes

- Routes are declared in `src/app/routes.tsx` and components live under `src/app/components/`.
- Static mock data is available at `src/app/data/mockData.ts` for local UI development.
- Use the existing UI primitives in `src/app/components/ui/` to keep styling consistent.
